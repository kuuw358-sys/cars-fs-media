# cars-fs-media

أدوات تصميم بوستات حساب CARS FS لإعلانات السيارات. القواعد كاملة في `CLAUDE.md`.

## القالب المعتمد
**`template/post.html` بمقاس 1080×1350 (4:5).** ما فيه قالب ثاني معتمد.

- **فوق:** الماركة بالعربي (مثل «لكزس») والموديل والفئة على اليسار، و«للبيع» على اليمين.
- **النص:** صورة السيارة داخل مربع بزوايا دائرية، وتعبي المربع كامل (`"photoFit": "cover"`).
- **تحت:** صف فيه 4 خانات (موديل، العداد، الصيانة، الفحص)، وبعده زر الرقم وزر السعر.
- الفئة (`trim`) تنكتب بس إذا مذكورة في كلام السيارة، وإذا مو مذكورة ما تنحط في ملف JSON وسطرها يختفي.

## طريقة الاستخدام
1. حط صورة السيارة **الأصلية** في `photos/` بعد ما تتغطى اللوحة (`tools/plate/`).
2. انسخ `cars/lexus-ux200.json`، وغيّر التفاصيل ومسار الصورة `photo`.
3. ارسم التصميم:
   ```
   node render.js cars/<car>.json
   ```
   الصورة تطلع في `output/<car>.jpg` (‏JPG بجودة 85).

خيار إضافي في JSON:
- `"photoPosition": "center 70%"` يحدد أي جزء من الصورة يبين إذا انقصّت أطرافها.

الخط: Cairo (رخصة SIL Open Font License)، موجود في `fonts/`.
